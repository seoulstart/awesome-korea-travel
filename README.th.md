# แหล่งข้อมูลที่ใช้ได้จริงสำหรับการเที่ยวเกาหลี

> วางแผนเที่ยวเกาหลี การเข้าเมืองและ K-ETA การเดินทาง เมืองต่าง ๆ อาหาร และฤดูกาล

รายการนี้ดูแลโดย [Seoulstart](https://seoulstart.com/?utm_source=github&utm_medium=referral&utm_campaign=awesome-korea-travel&utm_content=th) สำหรับคนที่จะไปเที่ยวเกาหลีใต้ เราวางเว็บไซต์ทางการและแหล่งข้อมูลต้นทางไว้ก่อน ส่วนคู่มือของ Seoulstart อยู่ข้าง ๆ ไม่ได้อยู่เหนือกว่า

> **หมายเหตุ**: ฉบับภาษาไทยนี้เป็นสรุปย่อของ README ภาษาอังกฤษ เนื้อหาทั้งหมดของ Seoulstart ดูได้ที่เว็บไซต์ภาษาอังกฤษ [seoulstart.com](https://seoulstart.com/?utm_source=github&utm_medium=referral&utm_campaign=awesome-korea-travel&utm_content=th)

## เว็บไซต์ทางการที่สำคัญ

- [VisitKorea (องค์การส่งเสริมการท่องเที่ยวเกาหลี)](https://english.visitkorea.or.kr/) - เว็บไซต์ท่องเที่ยวทางการ: สถานที่เที่ยว แผนการเดินทาง การเดินทาง และกิจกรรม
- [Korea.net](https://www.korea.net/) - อธิบายเรื่องวัฒนธรรม นโยบาย และประวัติศาสตร์ใน 10 ภาษา
- [K-ETA](https://www.k-eta.go.kr/) - การอนุญาตเดินทางอิเล็กทรอนิกส์ทางการสำหรับพลเมืองประเทศที่ได้รับยกเว้นวีซ่า มีเว็บปลอมเยอะ อันนี้คือของจริง
- [Korail](https://www.letskorail.com/) - จองตั๋วรถไฟ KTX และรถไฟทั่วประเทศอย่างเป็นทางการ
- [SRT](https://etk.srail.kr/) - รถไฟความเร็วสูงออกจากสถานีซูซอ (Suseo)
- [สนามบินอินชอน](https://www.airport.kr/ap/en/index.do) - ข้อมูลสนามบินนานาชาติหลักของเกาหลี
- [T-money](https://www.t-money.co.kr/) - บัตรเติมเงินใช้ขึ้นรถไฟใต้ดิน รถเมล์ และแท็กซี่
