# Полезные ресурсы для путешествия по Корее

> Планирование поездки в Корею, въезд и K-ETA, транспорт, города, еда и сезоны.

Подборку ведёт [Seoulstart](https://seoulstart.com/ru?utm_source=github&utm_medium=referral&utm_campaign=awesome-korea-travel&utm_content=ru) для тех, кто путешествует по Южной Корее. Официальные порталы и первоисточники идут первыми, а гайды Seoulstart стоят рядом с ними, а не выше.

## Главные официальные порталы

- [VisitKorea (Корейская туристическая организация)](https://english.visitkorea.or.kr/) — официальный туристический сайт: достопримечательности, маршруты, транспорт, события.
- [Korea.net](https://www.korea.net/) — объяснения о культуре, политике и истории на 10 языках.
- [K-ETA](https://www.k-eta.go.kr/) — официальное электронное разрешение на въезд для граждан безвизовых стран. Сайтов-двойников много, это настоящий.
- [Korail](https://www.letskorail.com/) — официальная продажа билетов на поезда KTX по всей стране.
- [SRT](https://etk.srail.kr/) — скоростные поезда от станции Сусо.
- [Аэропорт Инчхон](https://www.airport.kr/ap/en/index.do) — информация о главном международном аэропорте Кореи.
- [T-money](https://www.t-money.co.kr/) — пополняемая карта для метро, автобусов и такси.
